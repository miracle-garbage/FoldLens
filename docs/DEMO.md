# FoldLens 三分钟演示脚本

> 目标：在断网、只有笔记本的教室里，用一条命令启动并讲清“四处联动”。
> 演示前先跑一次 `./scripts/setup.sh`，确保依赖、6 个样例与缩略图就位。

## 0. 启动（约 10 秒）

```bash
./scripts/dev.sh
```

启动器会在就绪后自动打开 <http://localhost:5173>（Linux / Windows 均可）。后端在 127.0.0.1:8000，前端通过 Vite 代理 `/api`。

## 1. 首页（20 秒）

- 指出 6 个内置样例：1CRN、1UBQ、1LYZ、4HHB、6M0J、1L2Y。
- 说明样例与缩略图随项目打包，断网也能打开。
- 在搜索框输入 `1CRN`，按 Enter。

## 2. 四处联动（60 秒）

1. 默认 Cartoon、按二级结构着色；深色观察窗是结构，纸面是读数。
2. 在 3D 中点击一个残基，或点击右侧序列中的 `ALA 45`。
3. 指出残基卡同步显示 `φ / ψ / B-factor / 疏水性`。
4. 指出 Ramachandran 图中的朱红当前点、接触图中的朱红十字线。
5. 按 `← / →` 在当前链内移动，按 `Esc` 清空。

## 3. 视图与配色（40 秒）

- 切换 `Cartoon → Stick → Sphere`，说明不重建页面，只重设样式。
- 配色依次切到 `疏水性`、`B-factor`、`元素`，说明色阶范围与图例。
- 打开 4HHB：4 条链，按链显隐；在档案中展示 4 个 HEM 配体。
- 打开 6M0J：2 条蛋白链、791 个残基，说明较大结构仍可交互；接触图为 2,290 对。

## 4. 档案与导出（30 秒）

- 切到“档案”：实验方法、分辨率、沉积日期、链/残基/原子计数、配体、缺失残基、统计。
- 导出 CSV，打开第一行说明列与契约一致。
- 导出 PNG（当前 3D 帧）。
- 复制链接，刷新页面，选中残基与配色/表示方式恢复。

## 5. 语言与上传（30 秒）

- 切到 English，说明专业术语（PDB、Cα、Ramachandran、B-factor）保留英文。
- 上传一个本地 `.cif` / `.pdb`，说明只写入运行时缓存，不污染样例目录。

## 6. 收尾（10 秒）

- 说明技术栈：React + TypeScript + Vite；FastAPI + Biotite。
- 说明数据诚实：显示算法真实计算结果，缺失值显示 `—`；Ramachandran 允许区标注为近似。
- 说明范围：v1 不做配体口袋、表面渲染、结构对比、变异预测。

## 断网 / 故障兜底

- 断网时只打开 6 个内置样例；不要搜索新的 PDB ID。
- 若后端未启动：Vite 仍能显示首页骨架，但样例会报 `NETWORK`；重新运行 `./scripts/dev.sh`。
- 若端口被占用：`ss -ltnp | grep -E '5173|8000'`，关闭占用进程后再启动。
- 若 3D 未出现：确认 `frontend` 构建成功，且浏览器未禁用 WebGL；可先用 Stick 表示降低负担。
