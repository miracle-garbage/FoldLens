## 1. 项目概述

### 1.1 一句话

一个本地运行的蛋白质结构探索器：输入 PDB ID 或上传结构文件，在 3D 结构、序列、Ramachandran 图、残基接触图之间联动观察同一个残基。

### 1.2 目标

1. **看得见结构**：在浏览器里流畅渲染 mmCIF/PDB 结构，支持常用表示与配色。
2. **读得懂数据**：把结构背后的序列、二面角、接触关系、B-factor 变成可读的图表与数字。
3. **联得起来**：四处视图共享同一个残基选择，形成“点一下、四处响应”的体验。
4. **演示得出去**：本地一条命令启动，断网也能完整演示 6 个样例。
5. **讲得清楚**：代码中的每个生物信息学计算都有可解释的来源与参数。

### 1.3 成功标准

- 6 个样例全部可打开、可交互、可离线。
- 点击残基后四处同步高亮 < 100ms。
- 中英文界面完整，不出现半汉化。
- 设计检查在 1440 / 768 / 390 三档无 `FAIL`。
- 答辩现场从启动到打开 1CRN ≤ 10 秒（本机）。

### 1.4 非目标（v1 明确不做）

- 配体结合口袋分析、表面渲染、双结构叠合。
- 变异致病性预测模块。
- 多模型 ensemble 对比、分子动力学轨迹。
- 用户账户、收藏、云端同步、公网部署。
- 移动端专门适配（保证可打开、可用即可）。

## 2. 用户与场景

| 用户 | 场景 | 需求 |
|---|---|---|
| 生物信息学课程学生 | 课后理解某个 PDB 结构 | 快速打开、点残基、看序列与几何关系 |
| 课程教师 / 答辩评审 | 期末演示 | 启动简单、断网可跑、界面专业、解释得通 |
| 结构生物学初学者 | 第一次接触 PDB | 不需要学命令行，不需要装 PyMOL |

**典型任务流**

1. 打开首页 → 搜索 `1CRN` 或点样例卡。
2. 工作台加载 3D 结构，默认按二级结构着色。
3. 在 3D 里点击 45 号亮氨酸 → 序列、Ramachandran、接触图同时定位。
4. 切换配色到“疏水性”，观察该残基的环境。
5. 切到英文，复制链接，刷新后状态恢复。
6. 导出 CSV，结束。

## 3. 功能规格

### 3.1 首页

| 编号 | 功能 | 行为 |
|---|---|---|
| H-01 | PDB ID 搜索 | 输入 4 位字母数字；自动转大写、去空格；Enter 或按钮提交 |
| H-02 | 输入校验 | 非 4 位或含非法字符 → 输入框下方内联错误，不跳转 |
| H-03 | 搜索加载态 | 提交后按钮进入 loading，输入框禁用，防重复提交 |
| H-04 | 搜索错误态 | 404 → “未找到该 PDB 条目”；网络/超时 → 可重试提示 |
| H-05 | 样例画廊 | 6 张卡片：缩略图、PDB ID、名称、链数/残基数/分辨率 |
| H-06 | 样例打开 | 点击整卡进入工作台；键盘 Enter/Space 同样可打开 |
| H-07 | 示例 chips | `1CRN`、`4HHB`、`6M0J` 三个快捷 chip，点击填入并打开 |
| H-08 | 语言切换 | 右上角中文/English 切换，立即生效并持久化 |
| H-09 | 数据来源 | 页脚注明 RCSB PDB 与课程信息 |

**样例清单**

| PDB ID | 名称 | 选择理由 |
|---|---|---|
| `1CRN` | Crambin | 46 残基，最小经典样例，加载快 |
| `1UBQ` | Ubiquitin | 76 残基，常见教学对象 |
| `1LYZ` | Lysozyme | 129 残基，有配体与经典结构 |
| `4HHB` | Hemoglobin | 四聚体 + 血红素，多链与配体展示 |
| `6M0J` | Spike RBD–ACE2 | 蛋白-蛋白界面，较大结构性能测试 |
| `1L2Y` | Trp-cage | 20 残基，NMR 微型蛋白，视觉简洁 |

### 3.2 工作台

#### 顶部栏

- 返回首页。
- 当前条目：PDB ID（mono）+ 标题（截断时 tooltip 显示全文）。
- 表示方式：Cartoon / Stick / Sphere 分段控件。
- 配色方案：二级结构 / 链 / 残基位置 / 疏水性 / 电荷 / B-factor / 元素。
- 链显隐：多链结构显示 popover，复选框切换。
- 导出菜单：PNG 截图 / CSV 数据 / 复制链接。
- 语言切换。

#### 3D 视图

| 编号 | 功能 | 行为 |
|---|---|---|
| W-01 | 加载结构 | 从 `/api/entries/{id}/structure` 取 CIF 文本，3Dmol 解析 |
| W-02 | 默认样式 | Cartoon；按二级结构着色；深色背景 `#0C0F14` |
| W-03 | 相机 | 拖拽旋转、滚轮缩放、右键/双指平移；`zoomTo` 初始适配 |
| W-04 | 自动旋转 | 默认关闭；不在 UI 中提供，避免干扰读数 |
| W-05 | Hover | 悬停残基显示 tooltip：`LEU 45 · α-helix` |
| W-06 | 点击选中 | 点击残基 → 全局选中；点击空白 → 取消选中 |
| W-07 | 选中高亮 | 选中残基加 stick 样式 + 标签；保留原 cartoon |
| W-08 | 链显隐 | 隐藏链的同时保留相机；全部隐藏时显示空态提示 |
| W-09 | 尺寸变化 | 容器 resize 后调用 `viewer.resize()`，不重置相机 |
| W-10 | 卸载清理 | 组件卸载时 `clear()` 并释放 WebGL 上下文 |
| W-11 | 大结构提示 | 残基数 > 3000 时显示性能提示，接触图降采样 |

#### 序列面板

- 按链分组；每条链显示链 ID、残基数。
- 单字母序列，mono 字体；每 10 个残基显示一次序号刻度。
- 点击残基 → 全局选中；hover → tooltip（三字母名 + 序号）。
- 当前残基：朱红下划线 + 浅色底；自动滚动到可视区域。
- 缺失残基：用 `···` 占位并加虚线，tooltip 说明“未解析”。
- 配体不进入序列；在“档案”中列出。

#### 残基详情卡

| 字段 | 说明 |
|---|---|
| 残基标识 | `LEU 45` + 链 ID；插入码存在时显示 `45A` |
| 类型 | 蛋白质残基 / 配体 / 水（水默认不选中） |
| 二级结构 | α-helix / β-strand / coil，chip 形式 |
| φ / ψ | 度，保留 1 位小数；末端无值显示 `—` |
| B-factor | 该残基所有原子的均值，保留 2 位小数 |
| 疏水性 | Kyte–Doolittle 值，保留 2 位小数 |

未选中时显示提示：“点击结构或序列中的残基”，并提供一个“示例残基”按钮。

#### Ramachandran 图

- 横轴 φ（−180…180），纵轴 ψ（−180…180）。
- 全部蛋白质残基为散点；当前残基朱红实心 + 白环。
- 允许区/ favored 区用描边轮廓表示；异常点用 `danger` 色。
- 点击散点 → 选中对应残基；hover → tooltip。
- 无 φ/ψ 的残基（如末端、甘氨酸无侧链不影响）不绘制。
- 图例：普通点 / 异常点 / 当前残基。

#### 接触图

- 矩阵大小 = 蛋白质残基数；只绘制已解析残基。
- 接触定义：Cα–Cα ≤ 8 Å，且 `|i − j| ≥ 3`。
- 当前残基：横纵十字线 `accent`。
- 点击单元格 → 选中行对应的残基。
- hover → tooltip 显示两个残基标识。
- 残基数 > 3000 时：显示警告，图改为 2× 降采样渲染，并标注。
- 图例：接触 / 非接触 / 当前残基。

#### 结构档案

- 实验方法、分辨率（Å）、R-free、沉积日期。
- 链数、原子数、残基数、配体数。
- 配体列表：组成 ID、名称、链、序号、原子数。
- 缺失残基：按链列出范围，如 `A: 1–2, 78–80`。
- 无数据时显示 `—`，不猜测。

### 3.3 导出与分享

| 功能 | 行为 |
|---|---|
| PNG | 导出 3D 画布当前帧，文件名 `{pdbId}-{scheme}.png` |
| CSV | 列：`index, chain, res_id, ins_code, name3, name1, sse, phi, psi, b_factor, hydrophobicity` |
| 复制链接 | 复制含 `pdb/chain/res/scheme/repr` 的 URL；Toast 反馈 |

### 3.4 URL 状态

格式：

```
/entry/1CRN?chain=A&res=45&scheme=ss&repr=cartoon
```

- 打开时恢复条目、选中残基、配色、表示方式。
- 非法或不存在的残基 → 忽略选中，保留条目。
- 切换选中/配色/表示时使用 `replaceState`，不污染浏览器历史（打开条目除外）。
- 语言不写入 URL，存 `localStorage`。

### 3.5 上传

- 支持 `.cif`、`.mmcif`、`.pdb`；单文件 ≤ 50MB。
- 上传后进入与 PDB ID 相同的工作台；条目标识显示 `UPLOAD`。
- 上传文件只存内存/临时缓存，不写入 `data/samples/`。
- 解析失败 → 显示 `PARSE_FAILED` 错误卡与原因。

## 4. 交互规格：四处联动

**唯一选中状态**：`{ chainId, resId, insCode }`，存于 Zustand，并同步到 URL。

| 来源 | 事件 | 结果 |
|---|---|---|
| 3D 视图 | 点击残基 | 设为当前选中 |
| 3D 视图 | 点击空白 | 清空选中 |
| 序列 | 点击残基 | 设为当前选中 |
| Ramachandran | 点击散点 | 设为当前选中 |
| 接触图 | 点击单元格 | 选中行残基 |
| 任意 | Esc | 清空选中 |
| 任意 | ← / → | 在当前链内移动到上一个/下一个残基 |

**响应链**

1. 更新 store。
2. 3D：移除旧高亮，添加新高亮与标签。
3. 序列：滚动到可视区，更新高亮。
4. Ramachandran：更新当前点。
5. 接触图：更新十字线。
6. 残基卡：更新读数。
7. URL：`replaceState`。

**一致性要求**：同一个残基在四处必须使用同一组标识；如果某视图缺少该残基（例如配体不在序列中），该视图显示“不适用”，而不是静默错位。

## 6. 技术架构摘要

```
Browser (React :5173)
   │  /api 代理
   ▼
FastAPI (:8000)
   ├─ 路由层：entries / samples / upload / health
   ├─ 服务层：RCSB 拉取、缓存、Biotite 解析、分析计算
   └─ 数据：data/samples → .cache → RCSB
```

- 前端不直接访问 RCSB；所有外部请求经后端，便于缓存与离线。
- 后端不保存数据库；缓存是文件。
- 3Dmol 懒加载，避免拖慢首页。
- 完整契约、数据模型、算法见 `docs/ARCHITECTURE.md`。

## 7. 数据与算法规格摘要

| 计算 | 方法 | 参数 / 输出 |
|---|---|---|
| 解析 | Biotite `pdbx.CIFFile` + `get_structure(model=1)` | 第一个 model；保留 HETATM |
| 二级结构 | Biotite `annotate_sse`（P-SEA） | `NONE=-1, COIL=0, HELIX=1, STRAND=2` → `coil/helix/strand` |
| φ/ψ | `dihedral_backbone` | 弧度 → 度，保留 1 位；NaN → null |
| 接触 | Cα `CellList.create_adjacency_matrix(8.0)` | 对 `i<j`、`|i−j|≥3` |
| 疏水性 | Kyte–Doolittle 表 | 20 种氨基酸；未知 → null |
| B-factor | 残基内所有原子均值 | 保留 2 位 |
| 配体 | 非水 HETATM 残基分组 | 组成 ID、链、序号、原子数 |
| 缺失残基 | 链内观测序号断档 | `start–end` 范围；不推断末端缺失 |

完整实现细节见 `docs/ARCHITECTURE.md` 第 8 节。

## 8. 非功能需求

### 8.1 性能

- 首页首屏 JS（不含 3Dmol）≤ 250KB gzip。
- 3Dmol 独立 chunk，进入工作台才加载。
- 残基点击到四处更新 ≤ 100ms（1CRN/1UBQ）。
- 4HHB 在集成显卡上旋转 ≥ 30fps；不足时允许降到 Stick。
- 接触图渲染 ≤ 200ms（≤ 2000 残基）。
- 本地缓存条目 API 响应 ≤ 300ms。

### 8.2 可访问性

- WCAG 2.1 AA：正文对比度 ≥ 4.5:1；大字/图形 ≥ 3:1。
- 所有交互可键盘完成；焦点可见（2px `accent` 外框）。
- 图标按钮必须有 `aria-label`；图表必须有文本替代说明。
- 尊重 `prefers-reduced-motion`。
- 颜色不是唯一信息通道：二级结构配图例，异常点配形状/标签。

### 8.3 安全

- 后端只绑定 `127.0.0.1`。
- PDB ID 白名单正则 `^[A-Za-z0-9]{4}$`，统一大写。
- 上传限制 50MB，校验扩展名与内容可解析性；文件名不参与路径拼接。
- 禁止把用户输入拼进 shell 或文件路径。
- 不返回堆栈给前端；错误使用稳定错误码。
- CORS 仅允许 `http://localhost:5173` / `http://127.0.0.1:5173`（如直连）。

### 8.4 离线与缓存

- 样例优先读 `data/samples/{ID}.cif`。
- 其他条目请求 RCSB 后写入 `.cache/`，后续离线可用。
- 缩略图随项目打包，不依赖外网。
- 断网且无缓存 → 明确错误 + “打开内置样例”出口。

### 8.5 可维护性

- 类型安全：TypeScript strict；Python 全量类型标注。
- 单一数据源：选中状态只在 store；API 契约只在 `ARCHITECTURE.md`；颜色只在 token。
- 文档与日志强制同步（见 `AGENTS.md`）。

## 11. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 3Dmol 逐残基着色 / 选中回调 API 不熟 | M1 卡住 | M1 第一天做最小原型；必要时逐残基 `addStyle`，把逻辑封装在 `structure/style.ts` |
| Biotite 残基编号与 3Dmol 的 `resi/icode` 对不上 | 联动错位 | 用 4HHB/6M0J 验证；建立 `(chain, resId, insCode) → atom index` 映射；插入码单独测试 |
| 大结构（6M0J）渲染卡顿 | 演示体验 | 限制接触图规模；允许降级表示；不在 v1 做 6VXX 级别结构 |
